# Avaliação de Programação Web - React

Projeto desenvolvido durante a graduação em Análise e Desenvolvimento de Sistemas na Fatec Mococa.

A aplicação reúne dois exercícios práticos desenvolvidos utilizando React, React Router e gerenciamento de estado com `useState`.

## 🚀 Exercícios

### Exercício 1 — Cálculo do volume de uma piscina

Recebe comprimento, largura e profundidade e calcula o volume da piscina em metros cúbicos e litros.

### Exercício 2 — Cadastro de produtos

Permite cadastrar produtos informando:

- Nome
- Preço
- Quantidade

Os produtos cadastrados são exibidos em uma tabela, com cálculo do valor total e opção para excluir registros.
